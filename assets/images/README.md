# Aset runtime

- `Logo JAWS JACKET Emas Merah.png`: logo JAWS JACKET yang digunakan pada area hero.
- `fallback.svg`: ikon fallback.

`jackets/` berisi 20 foto produk (AVIF, JFIF, JPG, dan WebP), satu untuk tiap model di katalog. Nama file produk dipetakan secara eksplisit di `js/data.js`; jangan mengganti nama file tanpa memperbarui pemetaan tersebut. Logo PNG dipakai untuk hero dan favicon. Aset WebP lama di luar folder `jackets/` berasal dari katalog hiking sebelumnya dan tidak disertakan dalam paket toko.
